# SmartPreview для PhotoCraft

[English](README.md)

Живой предпросмотр канваса PhotoCraft на телефоне — как Mobile Preview для Photoshop.
Каждая правка, undo и переключение документа отправляют на телефон картинку документа
(не скриншот окна). На телефоне — симуляция вырезов камеры, скруглённых углов и опасной зоны.

| Папка | Что это |
| --- | --- |
| `connector/` | Коннектор для PhotoCraft (Python 3, без зависимостей) + панель управления в браузере |
| `android/` | Android-приложение SmartPreview: полноэкранный просмотр, зум, вырезы |
| `connector/viewer.html` | Просмотр в браузере телефона (iPhone и всё остальное) |
| `tests/` | Проверки: `python3 -m unittest discover -s tests` |

## Почему «плагин» — это коннектор, а не модуль внутри PhotoCraft

Плагины PhotoCraft — это WebAssembly-фильтры в песочнице: «plug-ins get no host imports
(no WASI, files or network)». Отправить кадр на телефон изнутри PhotoCraft нельзя.
Поэтому SmartPreview работает рядом: подключается к встроенному control-серверу PhotoCraft
(`127.0.0.1`, JSON lines, HMAC challenge-авторизация — токен никуда не отправляется),
следит за `revision` активного документа и при изменении экспортирует его.

## Установка

### Телефон (Android 7.0+)

1. Поставь `SmartPreview.apk` (со страницы Releases или собери командой ниже; `adb install -r SmartPreview.apk`).
2. Открой **SmartPreview**. На экране будет адрес телефона, например `192.168.1.25:8767`.

Порт 8767, а не 8765 — чтобы не конфликтовать с PS Preview.

### Компьютер (macOS; Windows/Linux — см. ниже)

1. Сохрани работу и закрой PhotoCraft.
2. Двойной клик по `SmartPreview.command` (или `python3 connector/smartpreview.py`).
   Коннектор сам откроет PhotoCraft с включённым control-сервером и откроет панель
   `http://localhost:8766/panel`.
3. В панели нажми **Найти телефоны** → **Добавить**. Или впиши адрес с экрана телефона.
4. Рисуй. **Стоп/Старт** — live-режим, **Отправить** — один кадр.

Если PhotoCraft уже был открыт обычным способом, панель покажет «Нет доступа к PhotoCraft»:
токен control-сервера в этом случае знает только сам PhotoCraft. Сохрани работу, закрой его
и нажми **Открыть PhotoCraft** в панели.

PhotoCraft запускается так (это делает коннектор):

```bash
open -a PhotoCraft --args --control 8975 --control-token-file "$HOME/Library/Application Support/SmartPreview/control.token" --automation-write-root "$HOME/Library/Application Support/SmartPreview/frames"
```

`--automation-write-root` — папка для временных кадров; другим автоматизациям в этой сессии
писать можно только туда. Читать файлы автоматизация не может вообще.

### iPhone и другие браузеры

Открой на телефоне адрес из блока «iPhone и другие браузеры» в панели, например
`http://192.168.1.10:8766/`. В Safari: **Поделиться → На экран «Домой»** — полноэкранный режим.

## Режим экспорта

У desktop-PhotoCraft нет вызова «отрендерить композит», поэтому кадр — это экспорт.
Любое предупреждение экспорта PhotoCraft показывает карточкой-уведомлением, а плоские форматы
для многослойного документа всегда предупреждают («N layer(s) flattened»).

| Режим | Как | Скорость | Уведомления в PhotoCraft |
| --- | --- | --- | --- |
| **Тихий** (по умолчанию) | многослойный TIFF → JPEG | экспорт 60–80 мс при 3 слоях; растёт со слоями (~0.6 с при 8, ~1–1.3 с до телефона при 11 полноэкранных заливках) | нет (только строка «Saved …» в статус-баре) |
| **Быстрый** | плоский TIFF → JPEG | ~35 мс экспорт, ~0.2 с до телефона | на каждый кадр многослойного документа |

PSD/PSB не используются: такой экспорт перепривязывает путь документа к файлу кадра,
и Cmd+S сохранил бы работу в папку SmartPreview. TIFF путь не меняет.
UI PhotoCraft во время экспорта не подвисает.

Конвертацию TIFF → JPEG и уменьшение делает `sips` (встроен в macOS). На Windows/Linux нужен
Pillow (`pip install pillow`); без него кадры идут PNG в размере документа, и многослойные
документы показывают уведомление.

## Управление на телефоне

| Жест | Действие |
| --- | --- |
| Тап в центре | Меню (прячется через 10 с) |
| Тап по левому / правому краю, кнопки громкости | Предыдущий / следующий вырез |
| Двойной тап | Вписать ↔ 1:1 |
| Щипок, перетаскивание | Зум и панорама |
| Ширина / Высота | Вписать по ширине или высоте |
| Опасная зона | Красное объединение областей вырезов и углов |

Пока приложение на экране, оно держит Wi-Fi в режиме низкой задержки: без этого
энергосбережение Wi-Fi задерживает кадры до секунды.

## Опции коннектора

```bash
python3 connector/smartpreview.py --help
```

- `--phones 192.168.1.25,192.168.1.26` — адреса телефонов (иначе сохранённые в панели)
- `--size 0|1080|1600|2400|4000` — длинная сторона, 0 = как в документе (по умолчанию 2400)
- `--fast` — быстрый режим экспорта
- `--discover` — найти телефоны в сети и выйти
- `--once` — отправить один кадр и выйти
- `--no-launch` — не запускать PhotoCraft
- `--token-file`, `--control-port` — для PhotoCraft, запущенного своими флагами

Настройки, токен и временные кадры: `~/Library/Application Support/SmartPreview/`
(Windows: `%APPDATA%\SmartPreview`, Linux: `~/.local/share/smartpreview`).

## Сеть и безопасность

- Кадры идут по **HTTP без шифрования и без авторизации**. Только доверенная Wi-Fi или приватный VPN (Tailscale, ZeroTier). Не открывай порты 8766/8767 в интернет.
- Просмотр в браузере (`:8766/`) доступен всем в локальной сети. Панель и её API отвечают только этому компьютеру (проверка адреса и `Host`, обязательный заголовок против CSRF).
- Control-токен PhotoCraft лежит в файле с правами `0600` и не передаётся по сети: коннектор доказывает знание токена через HMAC.
- «Найти телефоны» шлёт UDP broadcast и по одному UDP-пакету на адреса своей приватной /24-подсети.

## Сборка Android

Нужны Bash, JDK 17+, Android SDK platform `android-34`, Build Tools 35+. Без Gradle:

```bash
bash android/build.sh
```

APK появится в корне: `SmartPreview.apk`. Без переменных подписи используется отладочный
ключ `android/debug.keystore` (в `.gitignore`). Для релиза — `KEYSTORE` (alias `smartpreview`)
и `SIGNING_PASSWORD_FILE`, как в Mobile Preview.

Вьюер (вырезы, `cutouts.json`, жесты) взят из PS Preview; добавлены порт 8767, UDP-поиск,
имя документа в меню, приём JPEG/PNG/WebP, уменьшение огромных кадров при декодировании
и Wi-Fi low-latency lock. WebSocket-приём оставлен: панель Mobile Preview для Photoshop
может слать кадры и в это приложение (адрес `телефон:8767`).
